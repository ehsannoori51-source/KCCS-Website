Connect to GitHub

One-time step on each computer or phone. Saving writes your changes to GitHub, which updates the live site.

  1. Open github.com/settings/personal-access-tokens/new
  2. Name: KCCS admin. Expiration: 1 year.
  3. Repository access: Only select repositories → KCCS-Website
  4. Permissions → Repository → Contents: Read and write
  5. Click Generate token, press the copy button, and paste it below.
